# Security Policy

AllSafeX is an open-source Privileged Access Management (PAM) platform. The installation and development should follow our security guidelines.

For documentation and best practices, please visit [AllSafeX Documentation](https://jump.allsafex.com/).

## Reporting a Vulnerability

If you discover a security vulnerability within AllSafeX, please report it directly:

- **Security Team**: support@jump.allsafex.com
- **Website**: https://jump.allsafex.com/support
